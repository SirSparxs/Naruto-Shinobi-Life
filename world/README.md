# World foundation and canon divergence

Status: Established setting principles; Open world-data implementation.

Source: S0 initial user brief; S3 explicit permission for coherent non-canon techniques.

Use Naruto countries, villages, shinobi institutions, clans, chakra and history as the initial setting foundation appropriate to the selected era. Original NPCs, families, organizations and developments are allowed.

Canon events are not forced after believable divergence. Record what actually happens in campaign state. Reusable setting information belongs here; a campaign-specific injury, relationship or political change belongs in game-state.

Future setting records should distinguish setting-canon reference, original project creation and campaign-established fact, with era, source and design status. These provenance categories supplement rather than replace Established / Provisional / Open / Deprecated.

No world catalog or campaign history has been generated in this migration.
