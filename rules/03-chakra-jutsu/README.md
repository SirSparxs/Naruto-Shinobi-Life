Source: **Outline Chakra Ruleset** (S3 in [source index](../../migration/source-index.md)). The available conversation develops sections 3.1–3.4. Its broad outline is a backlog, not a complete set of approved mechanics.

Established user decisions: Chakra Control is a learned application, its expanded track has five levels with five tiers each except Master with seven, and coherent non-canon jutsu/techniques are permitted.

Provisional: reserve/recovery/exhaustion numbers, exact Control thresholds and benefits, proposed Output/Nature tracks, and other assistant-developed details not explicitly finalized.

Open: complete jutsu records, costs, learning and special-ability specifications. [Issue #3](https://github.com/SirSparxs/Naruto-Shinobi-Life/issues/3) owns this work.
