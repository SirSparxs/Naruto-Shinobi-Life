# 7.7 — NPC Memory

Status: Provisional design section pending explicit approval.

Ruleset 7.7 defines how NPCs remember past events, conversations, relationships, promises, injuries, betrayals, favors, discoveries, and emotional experiences.

The governing principle is:

**NPC memory should preserve socially meaningful causality without requiring perfect permanent storage of every interaction.**

Memory is not identical to objective history.

An event may have:
- an objective record;
- an NPC's personal memory of it;
- a distorted interpretation;
- incomplete details;
- uncertain source;
- emotional associations.

## 7.7.1 Memory Categories

Relevant memories may include:

### Event Memory
What happened.

Examples:
- completed a mission together;
- witnessed a fight;
- attended a funeral;
- escaped an ambush.

### Conversational Memory
Important things said.

Examples:
- confession;
- promise;
- threat;
- apology;
- warning;
- secret disclosure.

### Relationship Memory
Events that materially changed how the NPC relates to someone.

Examples:
- rescue;
- betrayal;
- abandonment;
- protection;
- humiliation;
- romantic milestone;
- repeated reliability.

### Knowledge Memory
Remembered information.

Examples:
- someone's address;
- mission details;
- a secret;
- password;
- evidence.

### Emotional Memory
How an event made the NPC feel.

Examples:
- terror associated with a location;
- warmth associated with a person;
- shame attached to failure;
- resentment after humiliation.

### Procedural / Habit Memory
Learned patterns or routines.

Examples:
- how someone behaves under pressure;
- a teammate's preferred combat habit;
- a partner's routine;
- which merchant can be trusted.

Ruleset 1 or other systems may own learned skills; this section focuses on remembered social and contextual information.

## 7.7.2 Memory Salience

Not every event deserves equal persistence.

Memory salience should depend on:
- emotional intensity;
- personal relevance;
- novelty;
- repetition;
- consequence;
- relationship importance;
- danger;
- humiliation;
- intimacy;
- surprise;
- recency;
- whether the event reinforced an existing belief.

High-salience memories persist longer and influence future behavior more strongly.

## 7.7.3 Salience Levels

Useful qualitative levels may include:

### Trivial
Small details unlikely to persist.

### Minor
Remembered temporarily or if reinforced.

### Notable
Likely remembered for a meaningful period.

### Major
Long-term persistent memory.

### Defining
Life-shaping event that may permanently affect identity, goals, or relationships.

Not every interaction needs an explicit label if the simulation can infer the appropriate level.

## 7.7.4 Repetition

Repeated low-intensity events may combine into a strong pattern memory.

Example:
One late arrival may be minor.

Ten late arrivals may produce:
- "Rex is unreliable with time."

This is different from storing ten equally important memories forever.

The simulation may compress repeated events into a learned pattern.

## 7.7.5 Pattern Memory

NPCs should learn recurring behavior.

Examples:
- keeps promises;
- lies when cornered;
- avoids conflict;
- always protects teammates;
- flirts with many people;
- becomes reckless when angry;
- refuses help until desperate.

Pattern memories may influence expectation even if individual incidents fade.

## 7.7.6 Emotional Weight

Strong emotions increase memory persistence.

Events involving:
- terror;
- grief;
- humiliation;
- love;
- jealousy;
- rage;
- relief;
- intense adult intimacy;
- betrayal;
- triumph;

may remain vivid longer.

Emotional memory may persist even when factual detail becomes fuzzy.

## 7.7.7 Relationship Weight

Events involving important relationships should receive higher salience.

A casual insult from a stranger may fade quickly.

The same insult from:
- a sibling;
- mentor;
- romantic partner;
- closest friend;

may remain significant for years.

## 7.7.8 Consequence Weight

Events with major practical consequences should persist.

Examples:
- someone caused permanent injury;
- someone saved the NPC's life;
- someone exposed a secret;
- someone caused demotion;
- someone helped secure promotion.

## 7.7.9 Memory Encoding

An NPC may fail to encode details accurately due to:
- distraction;
- stress;
- fatigue;
- intoxication;
- injury;
- panic;
- divided attention;
- poor visibility;
- overwhelming emotion.

Therefore memory quality should begin at the moment of experience.

## 7.7.10 Memory Accuracy

Memories may preserve:
- central event accurately;
- peripheral detail poorly.

Example:
An NPC clearly remembers being attacked but misremembers:
- exact time;
- clothing;
- sequence;
- bystander positions.

This is useful for witness testimony.

## 7.7.11 Source Memory

NPCs may remember a fact but forget where they learned it.

This can cause:
- misplaced confidence;
- accidental rumor repetition;
- believing speculation was firsthand knowledge.

Source memory may decay separately from content memory.

## 7.7.12 Memory Confidence

NPCs can be:
- certain;
- confident;
- unsure;
- vague;
- conflicted;

about their own memory.

Confidence does not guarantee accuracy.

## 7.7.13 Forgetting

Forgetting should usually affect:
- minor detail first;
- source attribution;
- exact wording;
- chronology;
- peripheral context.

Major emotional or defining events should decay slowly.

Forgetting should not behave like deleting a record instantly.

## 7.7.14 Memory Decay

Decay should depend on:
- salience;
- time;
- repetition;
- reinforcement;
- later related events;
- personality;
- cognitive condition;
- trauma;
- deliberate rehearsal.

A useful conceptual rule:

**Low salience + long time + no reinforcement = compression or loss.**

## 7.7.15 Reinforcement

Memory becomes more persistent when:
- discussed repeatedly;
- revisited physically;
- emotionally reactivated;
- supported by records;
- connected to later events.

## 7.7.16 Memory Distortion

Memories may change through:
- retelling;
- expectation;
- bias;
- rumor contamination;
- later information;
- emotional reinterpretation;
- self-protective rationalization.

Distortion should be plausible, not random.

## 7.7.17 Reconstruction

People often reconstruct rather than perfectly replay memory.

An NPC may remember:
- what they expected;
- what fits their current beliefs;
- what others repeatedly told them.

This creates realistic uncertainty in old events.

## 7.7.18 Memory Contamination

New information may alter old memory.

Example:
A witness initially remembers:
- "a tall masked shinobi."

After repeatedly hearing that Karn was responsible, they may later become less certain whether they actually recognized Karn.

The simulation should preserve the difference between original observation and reconstructed memory when important.

## 7.7.19 False Memories

False memories may develop through:
- suggestion;
- repeated misinformation;
- genjutsu or supernatural effects;
- severe confusion;
- self-deception.

Mundane false memory should be uncommon enough to remain meaningful.

Supernatural memory alteration remains owned by Ruleset 3.

## 7.7.20 Promises

Important promises should persist as explicit memory until:
- fulfilled;
- broken;
- released;
- renegotiated;
- forgotten only under extraordinary conditions.

Track:
- who promised;
- what was promised;
- conditions;
- deadline if any;
- perceived sincerity;
- fulfillment state.

## 7.7.21 Favors & Debts

Meaningful favors should create memory of:
- what was done;
- perceived cost;
- whether repayment is expected;
- whether gratitude remains.

The obligation system later determines the social consequence.

## 7.7.22 Insults & Humiliation

Insults should scale with:
- severity;
- audience;
- relationship;
- cultural meaning;
- sensitivity of the target.

Public humiliation may persist much longer than a private slight.

## 7.7.23 Betrayal Memory

Betrayals should be high-salience by default when meaningful trust existed.

Memory may preserve:
- what happened;
- what trust was violated;
- consequences;
- perceived motive;
- whether accountability occurred.

Reconciliation does not automatically erase betrayal memory.

## 7.7.24 Positive Landmark Memories

Positive events also deserve persistence.

Examples:
- first successful mission together;
- first confession of love;
- marriage;
- shared victory;
- life-saving rescue;
- birth of a child;
- mentor recognition.

Relationship systems should not only remember harm.

## 7.7.25 Romantic Memory

Romantic relationships may create memorable milestones:
- first meeting;
- first date;
- confession;
- first kiss;
- relationship formation;
- major intimacy milestone between adults;
- anniversary;
- proposal;
- breakup;
- reconciliation.

The importance depends on the characters, not on a mandatory checklist.

## 7.7.26 Adult Sexual Memory

For adults, explicitly sexual experiences may be remembered when relevant to:
- compatibility;
- trust;
- embarrassment;
- affection;
- desire;
- jealousy;
- relationship history;
- boundaries;
- trauma;
- future expectations.

The simulation may retain explicit detail when it materially matters to later behavior.

Such memories remain private unless revealed through plausible information flow.

A remembered sexual experience does not imply future consent.

## 7.7.27 Memory & Attraction

An NPC may associate someone with:
- safety;
- excitement;
- embarrassment;
- desire;
- rejection;
- comfort;
- danger.

These associations may affect future attraction, avoidance, or arousal without mechanically determining them.

## 7.7.28 Trauma-Related Memory

Severe events may produce unusually persistent or intrusive memories.

Ruleset 7 may track social and behavioral consequences.

Detailed medical or psychiatric effects should be owned by the appropriate health/condition system if later created.

Do not assume every traumatic event produces identical responses.

## 7.7.29 Suppression & Avoidance

An NPC may deliberately avoid thinking or speaking about an event.

Avoidance does not equal forgetting.

The event may still influence:
- mood;
- relationships;
- decisions;
- triggers.

## 7.7.30 Deliberate Rehearsal

Shinobi may intentionally memorize:
- mission details;
- faces;
- routes;
- codes;
- intelligence.

Training or expertise can improve retention where appropriate.

Ruleset 1 owns underlying capabilities.

## 7.7.31 Records as External Memory

NPCs may use:
- journals;
- mission reports;
- photographs;
- letters;
- archives;
- ledgers;
- intelligence files;

to recover forgotten details.

External records can correct or conflict with personal memory.

## 7.7.32 Shared Memory

Groups may develop shared narratives about events.

Examples:
- team remembers a disastrous mission;
- clan remembers historical betrayal;
- village commemorates a hero.

Shared narratives may diverge from objective history.

Institutional memory belongs partly to later faction/world systems, but personal belief remains governed here.

## 7.7.33 Memory & Reputation

Repeated reports about someone may form a remembered reputation even without direct interaction.

Example:
- "Everyone says she never abandons teammates."

This becomes expectation, not firsthand memory.

## 7.7.34 Memory Conflict

An NPC may hold conflicting memories or uncertainty about:
- sequence;
- motive;
- exact wording;
- identity of participants.

This should create uncertainty rather than forcing one version to become true.

## 7.7.35 Memory Correction

Memories may be corrected by:
- records;
- witnesses;
- confession;
- physical evidence;
- sensory evidence.

Correction may change belief without completely erasing the old emotional memory.

## 7.7.36 Relationship Reinterpretation

Old memories may acquire new meaning.

Example:
A gift once remembered as affectionate may later be reinterpreted as manipulation after betrayal.

Objective history remains unchanged.
Interpretation changes.

## 7.7.37 Memory Compression

To preserve long campaigns, multiple memories may be compressed into summaries.

Example:
Instead of storing twenty separate supportive conversations:

**Pattern:** Rena consistently supported Rex during academy failures, creating strong association of Rena with emotional safety.

Compression should preserve:
- pattern;
- emotional meaning;
- important exceptions;
- causal relationship effect.

## 7.7.38 Episodic Anchors

Even when memories are compressed, preserve specific landmark events as anchors.

Example:
- first mission failure;
- night of confession;
- betrayal at eastern gate.

Anchors make relationships feel historically grounded.

## 7.7.39 Memory by Simulation Tier

### Major NPC
Track:
- landmark memories;
- relationship-changing events;
- active promises;
- major knowledge;
- patterns;
- selected detailed episodic memories.

### Supporting NPC
Track:
- several important memories;
- active obligations;
- major pattern impressions.

### Persistent Minor NPC
Track:
- one or two notable encounters;
- broad impression.

### Background NPC
No persistent memory unless promoted or a consequential event occurs.

## 7.7.40 Memory Promotion

When a minor NPC becomes more important:
- preserve established encounters;
- expand compressed memories conservatively;
- do not fabricate detailed recollections that were never established.

## 7.7.41 Memory After Compression

Demotion must preserve:
- major betrayals;
- rescues;
- romance;
- family events;
- promises;
- debts;
- major conflicts;
- key secrets;
- defining emotional associations.

## 7.7.42 Forgotten Does Not Mean Deleted From History

The simulation may retain the objective historical event even if the NPC no longer remembers it.

This distinction enables:
- rediscovery;
- documentary evidence;
- other witnesses;
- later correction.

## 7.7.43 Player-Facing Memory

The player should not automatically know exactly what an NPC remembers.

Evidence may come from:
- conversation;
- behavior;
- repeated references;
- direct questions;
- successful social inference.

## 7.7.44 Memory-Based Difficulty

Past memories may modify future social interactions.

Examples:
- broken promise increases persuasion difficulty;
- repeated honesty improves credibility;
- prior humiliation increases resistance;
- positive intimacy increases comfort.

Ruleset 2 owns the actual resolution math.

## 7.7.45 Memory & Learning

Repeated social outcomes can teach NPCs:
- player's tactics;
- common lies;
- manipulation patterns;
- habits;
- vulnerabilities.

This may reduce effectiveness of repeated strategies.

## 7.7.46 Memory Audit

For a major relationship or mystery, the simulation should be able to answer:

1. What important events does this NPC remember?
2. Which details remain accurate?
3. Which are uncertain or distorted?
4. How did the event make them feel?
5. What belief or expectation did it create?
6. Has later information changed its interpretation?

## 7.7.47 Design Standard

A memory mechanic should be rejected or revised if it:
- remembers every trivial interaction forever;
- forgets major relationship events without cause;
- treats memory as perfectly accurate recording;
- randomly changes memories for drama;
- erases betrayal after reconciliation;
- stores only negative events;
- treats forgetting as deletion of objective history;
- exposes exact hidden memories to the player automatically;
- requires detailed episodic storage for background NPCs;
- makes compressed memories lose their causal effect.

## Governing Rule

**Remember what meaningfully changes future behavior, compress what becomes repetitive, let minor details fade, and preserve objective history separately from what any individual NPC currently remembers.**
