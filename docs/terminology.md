# Terminology

Status: Established for conceptual distinctions; mathematical conversions remain Provisional/Open.

| Term | Meaning / owning document |
|---|---|
| Attribute | Foundational capability: Agility, Intelligence, Strength, Endurance, Perception, Willpower, Chakra. |
| Skill | Learned application, represented with its own progression track. |
| Tier progress | Refinement within the current tier, 0–100; not the whole skill's capability score. |
| Technique mastery | Familiarity with one particular technique, distinct from its parent skill. |
| Derived capability | A value calculated when needed from attributes, skills and conditions. |
| Potential / soft limit | Hidden growth tendencies and increasing difficulty, not destiny or a hard rank cap. |
| Base / effective attribute | Persistent natural foundation / capability after current modifications. |
| Chakra reserves | Current and maximum usable resource; distinct from the Chakra attribute. |
| Chakra Control | Trained precision and efficiency; specialized 27-tier track. |
| Chakra Output | Throughput; proposed trainable skill plus derived limits, not total chakra cost. |
| Affinity / nature skill / jutsu | Natural inclination / trained elemental conversion / specific application. |
| Difficulty / stakes | Performance required / consequences of success or failure. |
| Capability margin | Effective capability minus task difficulty or opposing capability. |
| Outcome margin | Proposed success probability in percent minus random draw on the same scale. |
| Truth / knowledge / belief | Actual state / learned information / an actor's interpretation, possibly false. |
| Established | Current supported design; not synonymous with tested implementation. |
