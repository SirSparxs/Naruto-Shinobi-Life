# Deprecated and superseded ideas

Status: Deprecated entries below; historical evidence remains in reference excerpts.

| Historical idea | Why it is not current | Replacement |
|---|---|---|
| Initial eight-attribute list including Charisma and Chakra Control | Explicit S1 user revision chooses seven foundations | [Seven attributes](../rules/01-character-growth/attributes.md) |
| Early nine-attribute proposal with Speed, Reserves and Control as primaries | Superseded by the same explicit revision | Speed/Reserves derived; Control learned |
| Flat 0–100 skill as the entire skill system | User requested multi-tier growth and prerequisites | Track, tier and progress, separate from mastery |
| Simple five-level Chakra Control without the revised internal tier counts | User explicitly expands granularity | [27-tier Control](../rules/03-chakra-jutsu/chakra-control.md) |
| Rank as a hard growth cap or universal probability modifier | Conflicts with rank-generation and resolution distinctions | Contextual expectations; actual capabilities resolve actions |
| Alternative engine/campaigns and rules-folder layouts as separate maintained copies | Both were organizational proposals | One integrated simulation/ and game-state/ structure |
| Treating the Ruleset 3 outline as finished rules | User asked for an outline before developing sections | Open backlog plus developed 3.1–3.4 |

Earlier growth percentages, inheritance weights, rarity rates and 55/35/10 performance weights remain historical **Provisional** proposals where no explicit final replacement was approved. The current resolution working formula is S2's 60/30/10; do not combine both formulas.

Deprecated does not erase history. A return to an old idea requires a new explicit decision and an explanation of affected rules.
